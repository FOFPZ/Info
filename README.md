## Что это

Одна HTML-страница, которая притворяется терминалом:

- автозагрузка с приглашением `fofpz@anon:~$` и печатью команд;
- настоящий ввод команд: `help`, `whoami`, `about`, `projects`, `skills`,
  `stack`, `links`, `contact`, `privacy`, `neofetch`, `ls`, `cat`, `theme`,
  `clear` и другие;
- история ввода (`↑` `↓`), автодополнение (`Tab`), очистка (`Ctrl+L`);
- шесть тем оформления: зелёный фосфор, янтарный, холодный лёд,
  фиолетовая «purple-moon», багровая «crimson-alert» и светлая «paper-white»;
- иконки анонимности в консоли (команда `mask` и строка при загрузке):
  маска, инкогнито, луковица, замок — красятся цветом текущей темы;
- CRT-эффекты: строки развёртки, виньетка, лёгкое мерцание;
- вывод команд печатается по символам, структурированные строки появляются
  плавно; сверху медленно плывут приглушённые глифы фона (всё отключается
  при `prefers-reduced-motion` или параметром `?noanim`);
- название страницы — `??!?@#$@`;
- засекреченная дата `??.??.????`: вместо знаков вопроса живут случайные
  символы, ниже — строка «До того как я закрою доступ ко всему» и
  печатающаяся надпись «Эта дата очень секретна. Ее никто не узнает..»;
- мобильная версия, работа с клавиатуры и экранным чтецом,
  отключение анимаций при `prefers-reduced-motion`;
- страница `404.html` в том же стиле.

## Режим владельца

В шапке терминала есть кнопка **«войти»** (и команда `login`): открывается
диалог с полями «имя пользователя» и «пароль» (пароль маскируется).

- Вход проверяется прямо в браузере: в коде лежит только **SHA-256 хеш**
  пароля, сам пароль в репозиторий не попадает.
- После входа открывается команда `secret`, а сеанс владельца запоминается
  до закрытия вкладки (`sessionStorage`). Выйти — кнопка «выйти» или `logout`.
- Это демонстрация доступа на статичной странице, а не настоящая защита:
  всё содержимое страницы по-прежнему публично в исходниках.

## Иконки

В консоли живут четыре иконки анонимности (`mask`, а также строка при
загрузке): маска, инкогнито, луковица, замок. Это **собственные SVG-силуэты**
из `docs/assets/icons/` — нарисованы для этого репозитория, без чужих
лицензий, и красятся цветом текущей темы через CSS-маску.

Почему не готовые иконки с icons8: их бесплатная лицензия требует указания
ссылки на сервис, а сборочная среда физически не могла скачать бинарники
(сеть до CDN закрыта). Если хотите именно иконки icons8 — скачайте PNG
вручную и положите в `docs/assets/icons/` под именами из `profile.js`
(поле `icons`, например `mask.png` вместо `mask.svg`): консоль подхватит
их без правок кода. В этом случае добавьте на страницу и в README ссылку
«иконки: icons8.com» — этого требует их лицензия.

## Как править под себя

Всё содержимое страницы лежит в одном файле — [`docs/assets/profile.js`](docs/assets/profile.js).
Там псевдоним, факты, текст «обо мне», навыки, ссылки и правила приватности.
Меняете значения — страница меняется. Код трогать не нужно.

Локальный просмотр:

```bash
cd docs
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Публикация

Сайт публикуется через GitHub Pages из папки `docs/` этой ветки
репозитория. Сборка не нужна: это статичные файлы без зависимостей.

Подключение стилей и скриптов в `index.html` несёт метку версии (`?v=N`).
После любого обновления файлов сайта увеличьте её на единицу — иначе
браузеры могут продолжить держать старые копии скриптов из кеша.

## Приватность

- На странице **нет** аналитики, счётчиков, cookies, пикселей и рекламы.
- **Ноль сторонних запросов:** шрифты системные, стили, скрипты, значок
  и картинка предпросмотра лежат в этом репозитории.
- В браузере сохраняется только выбранная тема оформления, флаг сеанса
  владельца и локальный журнал сеансов — всё исключительно в пределах
  устройства посетителя.
- Журнал сеансов и команд (`who`, `history`, `sessions`, `journal`) живёт
  только в localStorage браузера текущего посетителя: каждый видит лишь
  собственную историю. Статичная страница без внешней аналитики не знает
  чужих посетителей — и мы такую аналитику не включаем.
- Коммиты подписаны анонимным адресом GitHub (`…@users.noreply.github.com`),
  настоящий адрес почты в истории не появляется.
- В файлах не публикуются: настоящее имя, личная почта, телефон, город,
  место учёбы или работы, дата рождения, личные страницы и фотографии.

### История коммитов

Почта, указанная в `git config`, навсегда остаётся в истории коммитов и видна
всем вместе с репозиторием. Чтобы вычистить её из уже существующей истории,
есть скрипт [`tools/scrub-history.sh`](tools/scrub-history.sh):

```bash
./tools/scrub-history.sh /путь/к/репозиторию \
  "123456+ВАШ_НИК@users.noreply.github.com" "ВАШ_НИК"
```

Он заменяет автора и коммитера всех коммитов на анонимный адрес noreply.
После него нужен force-push, а полная гарантия удаления старых данных с
GitHub — только пересозданный репозиторий. Подробности и меры предосторожности
— в комментариях внутри скрипта.
