## Команды

| Команда   | Что делает                              |
| --------- | --------------------------------------- |
| `help`    | список всех команд                       |
| `whoami`  | псевдоним и короткие факты               |
| `about`   | несколько абзацев о себе                 |
| `skills`  | навыки со шкалами                        |
| `stack`   | инструменты в виде тегов                 |
| `links`   | публичные ссылки                         |
| `contact` | как связаться (публичные каналы)         |
| `privacy` | что скрыто и почему                      |
| `neofetch`| сводка «о системе» с ascii-лого          |
| `ls`/`cat`| те же разделы, но в виде файлов          |
| `who`       | кто сейчас на сайте (этот браузер)         |
| `history`   | журнал введённых команд (локально)         |
| `sessions`  | история визитов этого браузера             |
| `journal`   | `journal clear` / `journal export`         |
| `login`     | вход в консоли: имя → пароль → проверка    |
| `logout`    | закрыть сеанс                              |
| `secret`    | заметка владельца (после входа как fofpz)  |
| `noloverme` | привет от noloverme (после его входа)      |
| `info`      | info от noloverme + его github             |
| `mask`      | иконки анонимности в консоли               |
| `timer`     | сколько осталось до 20.09.2027             |
| `theme`     | сменить тему (6 тем, список ниже)          |
| `clear`     | очистить экран                             |
| `log`       | открыть лог сайта                        |

Команды `projects` и `friend` больше не печатают списки: они открывают
соответствующие вкладки сайта — разделы теперь живут там.
