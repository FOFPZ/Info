## Что это

Одна HTML-страница, которая притворяется терминалом:

- автозагрузка с приглашением `fofpz@anon:~$` и печатью команд;
- настоящий ввод команд: `help`, `whoami`, `about`, `projects`, `skills`,
  `stack`, `links`, `contact`, `privacy`, `neofetch`, `ls`, `cat`, `theme`,
  `clear` и другие;
- история ввода (`↑` `↓`), автодополнение (`Tab`), очистка (`Ctrl+L`);
- три темы оформления: зелёный фосфор, янтарный, холодный лёд;
- CRT-эффекты: строки развёртки, виньетка, лёгкое мерцание;
- мобильная версия, работа с клавиатуры и экранным чтецом,
  отключение анимаций при `prefers-reduced-motion`;
- страница `404.html` в том же стиле.

## Команды

| Команда   | Что делает                              |
| --------- | --------------------------------------- |
| `help`    | список всех команд                       |
| `whoami`  | псевдоним и короткие факты               |
| `about`   | несколько абзацев о себе                 |
| `projects`| проекты: моды, плагины, лаунчер            |
| `skills`  | навыки со шкалами                        |
| `stack`   | инструменты в виде тегов                 |
| `links`   | публичные ссылки                         |
| `contact` | как связаться (публичные каналы)         |
| `privacy` | что скрыто и почему                      |
| `neofetch`| сводка «о системе» с ascii-лого          |
| `ls`/`cat`| те же разделы, но в виде файлов          |
| `theme`   | сменить тему (`green`, `amber`, `ice`)   |
| `clear`   | очистить экран                           |

## Как править под себя

Всё содержимое страницы лежит в одном файле — [`docs/assets/profile.js`](docs/assets/profile.js).
Там псевдоним, факты, текст «обо мне», навыки, ссылки и правила приватности.
Меняете значения — страница меняется. Код трогать не нужно.

Локальный просмотр:

```bash
cd docs
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Публикация

Сайт публикуется через GitHub Pages из папки `docs/` этой ветки
репозитория. Сборка не нужна: это статичные файлы без зависимостей.

## Приватность

- На странице **нет** аналитики, счётчиков, cookies, пикселей и рекламы.
- **Ноль сторонних запросов:** шрифты системные, стили, скрипты, значок
  и картинка предпросмотра лежат в этом репозитории.
- В браузере сохраняется только выбранная тема оформления.
- Коммиты подписаны анонимным адресом GitHub (`…@users.noreply.github.com`),
  настоящий адрес почты в истории не появляется.
- В файлах не публикуются: настоящее имя, личная почта, телефон, город,
  место учёбы или работы, дата рождения, личные страницы и фотографии.

### История коммитов

Почта, указанная в `git config`, навсегда остаётся в истории коммитов и видна
всем вместе с репозиторием. Чтобы вычистить её из уже существующей истории,
есть скрипт [`tools/scrub-history.sh`](tools/scrub-history.sh):

```bash
./tools/scrub-history.sh /путь/к/репозиторию \
  "123456+ВАШ_НИК@users.noreply.github.com" "ВАШ_НИК"
```

Он заменяет автора и коммитера всех коммитов на анонимный адрес noreply.
После него нужен force-push, а полная гарантия удаления старых данных с
GitHub — только пересозданный репозиторий. Подробности и меры предосторожности
— в комментариях внутри скрипта.
